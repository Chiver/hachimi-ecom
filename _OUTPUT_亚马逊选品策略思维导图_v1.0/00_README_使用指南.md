## 7 大战略 Cluster 速览

```
🟦 C1 数据驱动型选品 (Data-Driven Discovery)
🟩 C2 榜单 + 店铺复制 (Best-Seller & Shop Mimicry)
🟥 C3 痛点驱动差异化 (Pain-Point Differentiation)
🟧 C4 品牌化爆款打造 (Brand-First Hit Building)
🟪 C5 供应链反推 (Supply-Chain Reverse)
🟨 C6 趋势/节奏/渠道反向 (Trend Timing & Off-platform)
🟫 C7 AI / COSMO 原生选品 (AI-Native Selection · 2026 哈佛差异化护城河)
```

每个 cluster 含 4-7 个 L2 子策略，每个子策略含 7 项 schema：触发条件、数据源、决策链路、关键参数（含置信度+来源）、AI 化建议、典型案例、风险与反例。

## 建议使用流程

1. **第一次阅读**：打开 `02_选品策略_交互思维导图.html`，**先切到「🔗 全链路视图」看 11 模块串联框架（5 分钟）**，再切回「🌳 思维导图」逐 cluster 点击查看详情（45-60 分钟）
2. **团队培训**：HTML v2 完整覆盖策略本身 + 参数解读 + 对比案例 + 模块编排，单文件即可承担 2 小时培训
3. **AI Agent 工程化**：让工程团队基于 01 Markdown 把每个 L2 策略转化为 LangGraph / Claude Agent SDK 的 prompt；同时按 11 模块的 input/output schema 构建 Orchestrator
4. **每季度更新**：参数表会随亚马逊费率 / COSMO 算法 / 行业 SOTA 变化而调整，建议每 3 个月做一次 review

## HTML v2 新增能力一览

**思维导图视图**——每个策略点击后看到：
- 📖 策略详细叙述（4 段：哲学背景 / 流程逻辑 / 关键卡点 / 哈佛 AI 差异化做法）
- 🔬 参数深度解读卡片（6 个维度：是什么 / 为什么用 / 高了说明什么 / 低了说明什么 / 甜区含义 / 具体数字例子）
- ⚖️ 选品对比例子（✅ 应该选的真实产品 vs ❌ 不应该选的真实产品，含关键差异分析）
- 原有的 📊 数据源 / 🔄 决策链路 / 📐 参数速览 / 🤖 AI 建议 / 💡 案例 / ⚠️ 风险

**全链路视图**——11 模块串联：
- 模块 0：战略目标设定 → 1：选品策略漏斗 → 2：侵权与合规过滤 → 3：差异化设计 → 4：利润反推与定价 → 5：供应链锁定 → 6：Listing & 品牌资产 → 7：备货 & 物流 → 8：冷启动推广 → 9：数据迭代 & spec 升级 → 10：品牌化矩阵扩张
- 每个模块卡片含：📥 输入 / ⚙️ 模块内任务 / 📤 输出 / 🛠️ 关键工具 / ⚠️ 卡点 / 🔗 关联策略链接（可一键跳回思维导图查看详情）
